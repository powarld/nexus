# nexus
## Cadastro só por convite

1. No Supabase, abra **SQL Editor**, cole o conteúdo de `convites.sql` e rode **uma vez**.
2. No site, como admin: foto/perfil → **Conta** → **Convites de cadastro** → **Gerar código**.
3. Envie o link ou o código à pessoa. Cada código vale para uma pessoa e pode vencer ou ser revogado.

Contas que já existem não são afetadas. Pessoas novas sem código não conseguem criar conta (o bloqueio é no banco).
